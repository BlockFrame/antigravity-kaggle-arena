# Wiki: Skills & Core Modules Specification

This document details the core scripts and architectural components engineered specifically for the Antigravity Kaggle Arena.

---

## 1. Feature Engineering Suite (`src/core/feature_engineering_v2.py`)

### Purpose
Implements multi-representation feature engineering without requiring brittle manual tuning for every individual column.

### Key Capabilities
- **Digit Modulo Residuals (`col % 10`, `col % 5`, `col % 20`)**:
  Captures discrete rounding artifacts generated by deep generative synthetic models (e.g. CTGAN / TabDDPM) commonly used by Kaggle in the Playground Series.
- **Multi-Scale Binning (`// 5`, `// 10`, `// 25`)**:
  Creates broad categorization tiers, prompting decision trees to discover distinct early split points compared to raw continuous inputs.
- **Physiological / Domain Indices**:
  Calculates cardiac reserves (Tanaka formula: $208 - 0.7 \times \text{Age}$), cholesterol/blood pressure ratios, and Framingham-approximated cardiovascular risk proxies.
- **Group Z-Score Deviations**:
  Computes normalized deviations:
  $$Z = \frac{x - \mu_{\text{group}}}{\sigma_{\text{group}} + \epsilon}$$
  allowing gradient boosters to discern relative patient anomalies independent of baseline group scales.

## 2. In-Loop Bayesian Target Encoder (`src/core/in_loop_target_encoder.py`)

### Purpose
Eliminates out-of-fold target leakage during high-cardinality and discrete categorical encoding.

### Mathematical Formulation
For category $c$ with count $n_c$ and observed target mean $\bar{y}_c$, with global prior $\mu_{\text{prior}}$ and smoothing weight $m$:
$$\hat{S}_c = \frac{n_c \cdot \bar{y}_c + m \cdot \mu_{\text{prior}}}{n_c + m}$$

### Leakage-Free Implementation
- `fit_transform(X_train, y_train)`: Computes $\hat{S}_c$ strictly on the training partition of the active fold.
- `transform(X_val)`: Applies the frozen mapping onto validation samples, defaulting unseen categories to $\mu_{\text{prior}}$.

## 3. Tabular Residual Neural Network (`src/core/tabular_mlp.py`)

### Architecture
Designed specifically to provide statistical diversity against tree-based ensembles (achieving correlation $< 0.995$ against GBDTs).

```text
Input Features (Normalized)
       │
   Linear + LayerNorm + SiLU + Dropout
       │ ────────────┐ (Residual Skip Connection)
       ▼             │
   Linear + LayerNorm + SiLU + Dropout
       │ ◄───────────┘
       ▼
   Linear + LayerNorm + SiLU + Dropout
       │
   Linear Head ──> Sigmoid Output
```

## 4. Meta-Ensemble & Blending Suite (`src/core/ridge_ensemble.py`)

### Algorithms
1. **Rank Averaging Ensemble**:
   Normalizes raw out-of-fold probability vectors to uniform percentile ranks $R \in [0, 1]$ before computing convex linear combinations:
   $$P_{\text{blend}} = \sum_{m} w_m \cdot \text{Rank}(P_m)$$
   Guarantees scale-invariance and directly optimizes ranking metrics like **ROC-AUC** and **Gini**.
2. **L2-Regularized Ridge / Logistic Stacking**:
   Fits meta-learners with inverse regularizer $C$ on raw OOF vectors when non-linear calibration bounds are required.

## 5. Submission Integrity Gate (`src/core/verify_submission.py`)

### Validation Protocol
Before any prediction file is uploaded to Kaggle (preventing waste of daily submission quotas), this gate executes:
1. **Null / NaN Check**: Rejects any file containing missing entries.
2. **Infinite Bounds Check**: Flags overflow numerical values ($+\infty, -\infty$).
3. **Shape & Alignment Verification**: Asserts exact row count and identical column order matching `sample_submission.csv`.
4. **Probability Bounds Check**: Verifies that classification predictions remain strictly bounded within $[0.0, 1.0]$.
