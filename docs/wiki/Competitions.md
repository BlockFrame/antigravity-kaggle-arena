## Required page structure

Each future competition page includes the problem and metric, dataset/leakage audit, frozen validation contract, experiment ledger, compute environment, final design, separated OOF/Public/Private evidence, reproducibility boundary, skills and prompting decisions, limitations, and reusable lessons.

New competitions add a row here, a report under `docs/competitions/`, and implementation under `src/competitions/`.
